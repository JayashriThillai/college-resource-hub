# College Resource Hub

A full-stack web application that helps students upload, search, browse, and download academic resources organized by department and semester.

## Live Demo

https://college-resource-hub-sigma.vercel.app

## Features

- User Authentication (Supabase Auth)
- Upload study materials
- Download resources
- Search resources by subject
- Department-wise organization
- Semester-wise organization
- Cloud file storage
- Responsive UI

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Supabase Database
- Supabase Authentication
- Supabase Storage

### Deployment

## Installation

Clone the repository:

```bash
git clone https://github.com/JayashriThillai/college-resource-hub.git
```

Install dependencies:

```bash
npm install
```

Create `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_key
```

Run locally:

```bash
npm run dev
```
